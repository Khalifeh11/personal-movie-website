# Mood Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 7 mood buckets with 17 mood tags (1–3 per film), fetched TMDB keywords as evidence, and a site that browses by tag.

**Architecture:** One vocabulary file (`src/data/moods.json`) read by both the TS app and `enrich.mjs`. Hand-curated `data/mood-tags.json` is merged into every title on every `enrich` run by a pure `applyMoods`. The site swaps `moodBucket === slug` for `moods.includes(slug)` and reads labels from the vocabulary.

**Tech Stack:** Vite + React 19 + TS + Tailwind v4, Vitest, Playwright, Node ESM scripts.

**Spec:** `docs/superpowers/specs/2026-10-30-mood-tags-design.md`

## Global Constraints

- Vocabulary, order and labels exactly as the spec table: tense Tense · gritty Gritty · puzzling Puzzling · dread Dread · mind-bending Mind-bending · thought-provoking Thought-provoking · funny Funny · absurd Absurd · satirical Satirical · feel-good Feel-good · bittersweet Bittersweet · heartbreaking Heartbreaking · epic Epic · dreamy Dreamy · romantic Romantic · true-story True story · slow-and-quiet Slow & quiet.
- 1–3 moods per film; `moods` stored in vocabulary order.
- No new dependencies. Don't run `npm run dev`/`build`. Conventional commits.
- After UI changes, verify at 390×844 (Playwright mobile project or playwright-cli).

## Review Focus

1. Untagged title (`moods: []`) → still in All and the hero; Feels line hidden; no crash. (Task 3 tests.)
2. `enrich` without `--force` after editing `mood-tags.json` → moods update on skipped titles. (Task 1 test.)
3. Old bucket URL (`#/mood/on-edge`, `#/mood/moved`) → redirects home; `#/mood/mind-bending` still works. (Task 3 route test.)
4. Tags in the file out of vocabulary order (`["gritty","tense"]`) → stored as `["tense","gritty"]`. (Task 1 test.)
5. Title with no TMDB match → `keywords: []`, not undefined. (Task 1 transform test.)
